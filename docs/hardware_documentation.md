# AdmAIre - Hardware Connection Technical Documentation

This document contains the wiring specifications for the **AdmAIre** prototype, based on the **XIAO ESP32-S3 Sense** microcontroller.

---

### 1. Component List
* **Microcontroller:** Seeed Studio XIAO ESP32S3 Sense (with camera and microphone).
* **Batteria:** LiPo 3.7V 803450 (1500mAh) for long-lasting operation.
* **Amplificatori Audio:** MAX98357A I2S 3W DAC (x2).
* **Altoparlanti:** 8 Ohm Magnetic, 1W (x2).
* **Interruttore:** Slide Switch (SPST) for power-on/off.
* **Resistori** 100-200kΩ Resistors.

Component connections are specified within the **electrical-schematic** folder.
